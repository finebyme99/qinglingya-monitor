[完整项目存档（2026-10-19）](archive/2026-10-19/README.md)包含机器人本体、回调转接、业务规则、协作约束、数据库结构、测试和恢复说明。该目录是已发布版本的源代码快照，不含密钥和业务数据；上传存档不触发机器人部署，也不新增巡检任务。仓库保持私有。

## 现役外部监测

独立于 Cloudflare 的私有 GitHub Actions，每小时第17、47分钟探测，GitHub排队可能延迟。工作流设 `MONITOR_NOTIFICATIONS_ENABLED: 'false'`：巡检照常运行，但跳过 `pendingNotifications` 之后的飞书私信发送分支，包括手动演练。不发送群消息。生效状态以线上 main 分支配置和实际运行记录为准。

检查真实回调 challenge（最多两次）、受保护的只读健康入口、账号 UTC 日 Workers 请求、D1行读写、Durable Objects请求、运行时长与SQL读写行数。用量80%、95%、100%各提醒一次，UTC零点（北京时间08:00）重置。Analytics可能延迟或采样，不是实时账单承诺；后台显示与API统计应分别保留。健康检查包括计划、心跳、逐页正式投递和按钮任务失败。

issue #1 保存机器去重状态，不保存凭证或业务问题正文。关闭通知仍保留真实故障、日志、`last_check`、`fault_count` 和状态保存；真实故障仍使工作流退出1，额度预警和演练保持原退出规则。未发送的告警不新增 `sending` / `sent` 或消息ID，也不重置已发送及回执未知的历史记录。只有显式字符串 `'false'` 关闭；恢复 `'true'` 或移除此配置时，原有固定本人私信和去重逻辑恢复。

开启通知时，发送前保存UUID；未知回执停止自动重发。连续同一异常只提醒一次，探测恢复后重新布防；正常恢复不另发消息。私信失败使工作流失败，需核对日志和去重台账。

依赖仓库四项Secrets：MONITOR_TOKEN（运行摘要读取及固定监测心跳）、CLOUDFLARE_API_TOKEN（本账号Analytics只读）、FEISHU_APP_SECRET、FEISHU_VERIFICATION_TOKEN（真实challenge验证），以及GitHub自动注入的GITHUB_TOKEN。不得提交凭证文件。

标准Linux runner每月约1440–1488次，单次目标不足1分钟；每月预计约1500免费分钟。长超时会增加用量，免费分钟为账号共享。没有启用付费计划或扩大付费预算。源程序不调用模型。

检查按原条件向受保护的 `/monitor/heartbeat` 回报服务器时间，通知关闭不影响心跳。不要停掉整个工作流。内部机器人另有运行失败、按钮失败和外部心跳超过90分钟的私信路径，需要在机器人Worker的配置中同时设 `ALERT_NOTIFICATIONS_ENABLED: "false"`；仅推送本仓库不能改变机器人配置，不修改正式发送计划。存储容量和其他Cloudflare产品额度不在本次监测范围内。

本地测试：`node --test test/*.test.mjs`，只用模拟请求和虚构凭证。覆盖关闭通知不调用飞书认证/发送接口、故障结果和心跳保留、CLI故障退出1、重新开启后的通知，以及定时工作流仍启用。提交、推送或部署需另行确认。
